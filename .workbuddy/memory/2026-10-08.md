### 经验
- Copy 节点会分配新 ID，descendants 覆盖必须在同一次 Copy 里做，或拷完后 batch_read 拿真实 ID 再 U()。
- flex 父容器内元素 x/y 无效，需 `layoutPositioning:"ABSOLUTE"`。
- 本机 Git Bash 下 /tmp 文件用 Read 读不到，需 cp 到项目目录。
